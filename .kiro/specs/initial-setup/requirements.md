# 要件定義書 (Requirements Document)

## プロジェクト概要 (Project Description)
Meeting Vibe Check (MVP) の初期開発環境構築と、表情解析・ダッシュボードの基礎構造の確立。

## 要件 (Requirements)

### 1. 開発環境のセットアップ
- **1.1** Python 3.9以上を利用した仮想環境の構築。
- **1.2** 必要なライブラリ（Streamlit, Py-Feat, OpenCV-Python, Pandas, NumPy）のインストール。

### 2. プロジェクト構造の確立
- **2.1** `src/` ディレクトリを基点としたモジュール構成の作成。
- **2.2** `src/analysis/` への表情解析ロジック（Py-Feat）の配置。
- **2.3** `src/ui/` への Streamlit によるUIロジックの配置。

### 3. 表情解析エンジン (Py-Feat) の初期化
- **3.1** 軽量な解析モデル（SVMまたはRandom Forest）の選択。
- **3.2** Webカメラからのフレーム取得と Py-Feat への受け渡しフローの定義。

### 4. リアルタイムダッシュボード (Streamlit) の基礎
- **4.1** 解析結果をリアルタイムに表示するプレースホルダーの作成。
- **4.2** グラフ（感情の推移）を表示するための領域確保。

### 5. プライバシー保護の遵守
- **5.1** 画像データをディスクに保存しない処理フローの構築。
- **5.2** メモリ管理の徹底（解析後の即時破棄）。

### 6. パフォーマンス目標
- **6.1** 1ループのレイテンシを2秒以内に収める設計。
