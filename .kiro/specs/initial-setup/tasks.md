# Implementation Plan: initial-setup

## Tasks

- [ ] 1. プロジェクト基盤の構築
- [ ] 1.1 (P) 開発環境のセットアップ
  - Python 3.9+ 仮想環境の作成と有効化
  - 必須ライブラリ（Streamlit, Py-Feat, OpenCV-Python, Pandas, NumPy, streamlit-webrtc）のインストール
  - 依存関係を管理するための `requirements.txt` または `pyproject.toml` の作成
  - _Requirements: 1.1, 1.2_

- [ ] 1.2 (P) ディレクトリ構造の初期化
  - `src/` を基点としたディレクトリ構成（`src/analysis/`, `src/ui/`）の作成
  - 各ディレクトリへの `__init__.py` の配置によるモジュール化
  - _Requirements: 2.1, 2.2, 2.3_

- [ ] 2. 表情解析エンジン (Py-Feat) の実装
- [ ] 2.1 表情解析クラスの構築
  - Py-Feat の HOG-PCA および SVM モデルを使用した初期化ロジックの実装
  - 画像フレーム（NumPy配列）を入力とし、感情確率の辞書を返す推論メソッドの実装
  - _Requirements: 3.1, 3.2, 6.1_

- [ ] 2.2 プライバシー保護とメモリ管理の実装
  - 解析後の中間データおよび画像フレームをメモリから即時破棄する処理の統合
  - ファイル出力や外部送信が行われていないことのコードレベルでの確認
  - _Requirements: 5.1, 5.2_

- [ ] 3. リアルタイムダッシュボード (Streamlit) の実装
- [ ] 3.1 (P) WebRTC ビデオストリーミングの実装
  - `streamlit-webrtc` を使用したブラウザからのカメラ映像取得の実装
  - `video_frame_callback` 内で表情解析エンジンを呼び出すパイプラインの構築
  - スレッドセーフなキューを使用した解析結果のメインスレッドへの転送
  - _Requirements: 3.2, 5.1_

- [ ] 3.2 リアルタイム可視化 UI の構築
  - 現在の主要な感情を表示するメトリクスとプレースホルダーの配置
  - `st.line_chart` を使用した感情スコアの時系列グラフ表示の実装
  - _Requirements: 4.1, 4.2_

- [ ] 4. システム統合とパフォーマンス検証
- [ ] 4.1 エンドツーエンドの動作確認
  - カメラ起動から解析、グラフ更新までの一連のフローが動作することを確認
  - 解析ループのレイテンシを計測し、目標の2秒以内であることを検証
  - _Requirements: 6.1_

- [ ] 4.2* テストカバレッジの拡充
  - 表情解析ロジックのユニットテストの実装（ダッシュボード非依存）
  - 無効な画像入力に対するエラーハンドリングの検証
  - _Requirements: 3.1, 3.2_
